### Smart Ambulance & Traffic Priority System

An IoT-powered emergency traffic management system designed to create a **Green Corridor** for ambulances.

### 🔥 Key Features

- 📍 GPS-based ambulance tracking
- 📡 LoRa-based communication
- 🚦 Automated traffic signal priority
- 🏥 Hospital notification system
- 🚨 Emergency alert mechanism
- 🔵 Emergency vehicle blue-light signaling
- 🛣️ Traffic-aware route optimization
- ☁️ Cloud-connected architecture

### ⚡ Hardware

`ESP32` `GPS Module` `LoRa` `GSM` `OLED` `Traffic Signals` `IoT Sensors`

### 🧠 Software
